## Short product description

Bedir AI helps readers explore Quran and hadith sources through AI answers with inspectable quotations and source links. Our early-access product focuses on the Battle of Badr and supports Turkish, English, German and Arabic. We use the Claude API with document citations to generate answers from a focused corpus. Started in March 2026, we are expanding the corpus and plan to evaluate citation accuracy.

## Claude integration, if asked

Our server sends corpus entries to the Claude API as text documents with citations enabled and prompt caching configured. The interface displays the returned quotations and links to the sources. The current corpus contains 41 Quran entries and 70 hadith entries. Topic-based retrieval and a published citation-accuracy evaluation are planned, not existing capabilities.

## Planned use of support, if asked

API credits would support early-access inference and the development of a citation-accuracy evaluation across our four supported languages as we expand the corpus.

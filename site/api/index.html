API dokümantasyonu

Bedir AI'nın demo uç noktası: bir soru alır, yayınlanmış korpusumuzdan belgeleri Claude Messages API'sine document olarak verir, sunucu taraflı atıfla dönen yanıtı ve alıntılandığı metni yayınlar. Açık CORS ile çalışır, yani tarayıcı konsolundan doğrudan deneyebilirsin.

Uç noktalar

Uç noktaNe yapar
POST /api/askSoruyu yanıtlar; yanıtın dayandığı alıntıları, kimliği ve yayıncı bağlantısını döner.
GET /api/waitlistBekleme listesindeki kayıt sayısını döner: {"count": n}.
POST /api/waitlistE-posta ekler: {email, lang, source}. Mükerrer kayıt 200 döner, honeypot alanı _gotcha doluySA kaydedilmez.
GET /data/corpus.jsonYanıtların türediği 111 belge; sürüm numarası ve kaynak listesini de içerir.

İstek

curl -X POST https://bedirsavasi.com/api/ask \
  -H "content-type: application/json" \
  -d '{"q": "Bedir'de yardım hangi ayette geçiyor?", "lang": "tr"}'

Alanların anlamı

    

      
AlanAnlamı

      
        
answer[].textYanıtın metni; cümlelerin sonunda [n] atıf işaretleri bulunur.
        
answer[].cites[]Atıf: id korpus kimliği (Q3:123, B3950, M1763), title yayıncı numaralandırmasıyla başlık, url quran.com veya sunnah.com bağlantısı, quote belgeye birebir ait alıntı parçası.
        
providerclaude: yanıtı veren motor. Yanıtlar claude-haiku-4-5-20251001 ile, günlük bütçeyle sınırlı olarak üretilir; başka bir model yanıt vermez.
        
usageinput / cache_read / cache_write / output token sayıları; cache çalışıp çalışmadığını buradan görebilirsin.
        
retrievaldocuments_sent: istek başına gönderilen belge sayısı - her zaman tüm koleksiyon, çünkü önbellek öncü kısmının her soruda aynı kalması gerekiyor. mode: filtered ise sorudaki ayırt edici terimler öncelik listesini daralttı (en fazla 24 pasaj), full ise daraltacak terim bulunamadı.

500not_configuredUç noktanın API anahtarı yok.

502upstreamClaude'a ulaşılamadı ya da hata döndü.
        
503daily_budgetGünün demo bütçesi bitti; uç nokta UTC 00:00'a kadar Claude'u yeniden çağırmaz.

Sınırlar

        
  • Yanıtlar claude-haiku-4-5-20251001 ile üretilir: prompt cache sayesinde soğuk soru 30-65 bin token yazar, sıcak soru yaklaşık 130 taze token öder (ölçüldü). Uç noktanın günlük bir token bütçesi var; aşıldığında Claude'a gitmez ve bir sonraki UTC gününe kadar daily_budget döner.
  • Bu bir demo uç noktasıdır: kimlik doğrulama yok, hız sınırı IP başınadır, SLO yoktur.
  • Koleksiyon Bedir Savaşı ile sınırlıdır; kapsamadığı bir soru sorulduğunda uydurmak yerine kapsamadığını söyler.
  • Alıntılandığında birebir alıntı quote alanındadır; ama alıntının doğruyu desteklemesi ayrı bir iştir - bu korpusla ölçümü eval/ klasöründe yazdık ama henüz koşmadık.

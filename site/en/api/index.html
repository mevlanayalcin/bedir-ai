API documentation

The demo endpoint of Bedir AI: it takes a question, hands the published corpus to the Claude Messages API as document blocks, and returns the answer together with the verbatim passage it was drawn from. CORS is open, so you can call it straight from a browser console.

Endpoints

EndpointWhat it does
POST /api/askAnswers a question and returns the quotations the answer rests on, with ids and publisher links.
GET /api/waitlistReturns the number of stored waitlist signups: {"count": n}.
POST /api/waitlistAdds an email: {email, lang, source}. A duplicate returns 200; if the honeypot field _gotcha is filled nothing is stored.
GET /data/corpus.jsonThe 111 documents the answers come from, including its version and source list.

Request

curl -X POST https://bedirsavasi.com/api/ask \
  -H "content-type: application/json" \
  -d '{"q": "Which verse describes the help given at Badr?", "lang": "en"}'

Field meanings

    

      
FieldMeaning

      
        
answer[].textThe answer; factual sentences end with an [n] citation marker.
        
answer[].cites[]The citation: id is the corpus id (Q3:123, B3950, M1763), title names the passage as the publisher numbers it, url points at quran.com or sunnah.com, quote is the verbatim span taken from the document.
        
providerclaude or fallback. We name the engine that answered rather than claiming credit for Claude. Answers come from claude-haiku-4-5-20251001 behind a daily budget on this endpoint.
        
usageinput / cache_read / cache_write / output token counts; you can see whether prompt caching hit.
        
retrievaldocuments_sent: documents shipped per request - always the whole collection, because the cached prefix has to stay identical for every question. mode: filtered when distinctive terms narrowed the priority list inside the question (up to 24 passages), full when they did not.

Limits

        
  • Answers are produced by claude-haiku-4-5-20251001: with prompt caching a cold question writes a 30-65k token cache and a warm one pays about 130 fresh input tokens (measured). The endpoint has a daily token budget; past it we stop calling Claude, the backup engine answers, and provider says so.
  • This is a demo endpoint: no authentication, the rate limit is per IP, and there is no SLA.
  • The collection is scoped to the Battle of Badr. On a question it does not cover, it says so instead of inventing an answer.
  • The verbatim span is in quote, but a quotation supporting the wrong claim is a different problem: we wrote the measurement for that (eval/) and have not run it at scale yet.

Bedir AI

Bedir AI is an educational answer product over Islamic primary sources. A question asked in natural language is answered from a curated collection of Qur'an verses and hadith, and the interface shows the exact passage each answer was drawn from, with a link to the source.

How the Claude API is used

The answer endpoint passes the corpus to the Claude API as text documents with server-side citations enabled, one document per verse or hadith, with a cache_control breakpoint on the last document so the collection is read from prompt cache on repeat questions. Claude is instructed to answer only from those documents, to reply in the language of the question, and to state when the current collection does not cover a topic rather than fall back on parametric knowledge. The server maps the returned document_index values back onto corpus entries and renders the quoted text plus a link to quran.com or sunnah.com.

All inference runs against the first-party Claude API through the Claude Console — not AWS Bedrock or Google Vertex AI. Anthropic is currently the only model provider in the product.

Engine and demo limits

Answers are produced by claude-haiku-4-5-20251001 through the Claude Messages API: the collection is passed as document blocks with server-side citations and prompt caching enabled. Measured: a cold question writes the cached collection once (30,000 to 65,000 tokens depending on the language) and later questions read it back for roughly 130 fresh input tokens. The public demo has a daily token budget; once it is spent, the endpoint stops calling Claude until the next UTC day and the page shows a labelled recorded example instead. No other model answers.

Policy posture

  • AI disclosure. The answer interface states that users are talking to an AI assistant and that answers are generated from cited sources and may contain errors.
  • No religious rulings. Bedir AI is an information tool. It does not issue fatwas and refers users to a qualified scholar when asked for one.
  • Inspectable sources. Every source text the product uses is published openly, with its own link to the publisher.
